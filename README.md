# 📊 Recipe Traffic Prediction

This project focuses on predicting whether recipes would attract high website traffic, with the goal of improving user engagement and ad revenue.

---

## 🔹 Project Overview
- Designed a **machine learning solution** to classify recipes into high-traffic or low-traffic categories.  
- **Dataset**: 895 observations with 8 features.  
- Applied **data cleaning and validation**: handled missing values, duplicates, and outliers.  
- Used **Yeo-Johnson transformation** to normalize skewed data.  

---

## 🔹 Exploratory Data Analysis (EDA)
- Conducted **descriptive statistics** to understand feature distributions.  
- Generated **correlation plots** to detect feature relationships.  
- Performed **category-based traffic analysis** to identify key drivers of recipe popularity.  

---

## 🔹 Modeling
- **Logistic Regression (baseline)** → Achieved ~80% accuracy and precision.  
- **Decision Tree** → Overfit the data and performed worse than Logistic Regression.  

---

## 🔹 Business KPI
- Defined **High Traffic Conversion Rate (HTCR)** to track model performance post-deployment.  
- Results highlighted **Vegetable**, **Potato**, and **Pork** recipes as top traffic drivers.  

---

## 🚀 Key Takeaways
- Logistic Regression provided a robust baseline model.  
- Category-specific features strongly influenced recipe popularity.  
- Business-focused KPIs help connect model performance with real-world impact.
